# 📊 Estadísticas con Kotlin

Aplicación de consola en **Kotlin** que almacena exactamente **100 números enteros** (aleatorios o introducidos por teclado) y calcula su **media**, **moda** y **desviación típica** mediante un menú interactivo.


---

## ✨ Características

- 🎲 Generación de 100 números aleatorios (entre 1 y 100)
- ⌨️ Introducción manual de los 100 números, uno por línea o varios separados por espacios
- 📈 Cálculo de media, moda y desviación típica
- 🧭 Menú que se repite hasta elegir la opción de salir
- 🛡️ Validaciones: lista vacía, exactamente 100 datos, opciones de menú y entradas numéricas
- 🧩 Código organizado en funciones (`main()` solo arranca el menú)

## 📋 Menú

```
===== ESTADÍSTICAS CON KOTLIN =====
1. Generar 100 números aleatorios
2. Introducir 100 números manualmente
3. Mostrar números
4. Calcular media
5. Calcular moda
6. Calcular desviación típica
7. Calcular todas las estadísticas
8. Salir
Seleccione una opción:
```
